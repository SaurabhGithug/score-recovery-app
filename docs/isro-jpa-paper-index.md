# ISRO JPA previous-year papers

Checked on 19 September 2026. This collection contains 11 publicly downloadable question-paper PDFs found in ISRO/PRL archives and wider web search. The first page of each was checked for the post and year. Older ICRB papers were common to Assistant and Junior Personal Assistant; PRL conducted separate recruitment.
